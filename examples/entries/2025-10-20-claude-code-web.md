## What's new
Start Claude Code tasks from the browser or phone. Each task runs in its own cloud sandbox against a GitHub repo, and several can run in parallel.

## When is it safe to use
Research preview. Code runs in an isolated sandbox with limited network access, and changes arrive as a branch or pull request, so review before you merge.

## Use case and value
Hand off a bug fix or a test backlog while you are away from your laptop. Value: background work across repos without tying up your machine.

## How to implement
Connect GitHub at `claude.ai/code`, pick a repo and environment, describe the task, then review the pull request it opens.
