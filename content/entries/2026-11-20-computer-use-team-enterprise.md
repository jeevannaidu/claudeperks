## What's new
Computer use lets Claude see a user's screen and work in the desktop apps they allow. It works in the new Claude experience in Claude Desktop. It also works from Claude on the web and Claude Mobile where Computer access is on. It is now in beta on Team and Enterprise plans.

## When is it safe to use
Beta. It is rolling out to organizations gradually. Claude works only in the desktop apps the user allows.

## Use case and value
Example: an operations analyst asks Claude to copy figures between two desktop apps that have no connector. The analyst skips the manual copy and paste.

## How to implement
Follow the Set up computer use for Team and Enterprise plans article linked from the [apps release notes](https://support.claude.com/en/articles/12138966-release-notes).
