## What's new
Computer use lets Claude see a user's screen and work in the desktop apps they allow. It works in the new Claude experience in Claude Desktop. It also works from Claude on the web and Claude Mobile where Computer access is on. It is now in beta on Team and Enterprise plans.

## When is it safe to use
Beta. It is rolling out to organizations gradually, so it might not be visible yet. Claude works only in the desktop apps a user allows.

## Use case and value
Example: a user asks Claude to move data between two desktop apps that have no connector. Claude does the clicks in the apps the user allowed.

## How to implement
Admins set it up for the organization. The release notes link to the help article "Set up computer use for Team and Enterprise plans". Docs: https://support.claude.com/en/articles/12138966-release-notes
