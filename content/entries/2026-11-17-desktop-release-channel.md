## What's new
Claude Desktop now has a release channel setting. It controls which version you get when the app updates. Stable is the default and gets new versions less often, after more testing. Latest gets a new version about once a day.

## When is it safe to use
Generally available, inferred because the note has no beta label. Stable is the default, so nothing changes unless you opt in to Latest.

## Use case and value
Example: a power user who wants new features the day they ship picks Latest. A team that values steady behavior stays on Stable.

## How to implement
Open Claude Desktop and choose a release channel in its settings. The exact steps are in the Choose a release channel article linked from the [apps release notes](https://support.claude.com/en/articles/12138966-release-notes).
