## What's new
Claude Opus 4.8 (`claude-opus-4-8`) supports a 1M token context window by default and 128k max output tokens. It launched together with mid-conversation system messages: on Opus 4.8 you can send `role: "system"` messages after a user turn, so prompt cache hits are preserved when instructions change during a long session. The `effort` parameter defaults to high, and setting `temperature`, `top_p` or `top_k` to a non-default value returns a 400 error.

## When is it safe to use
Generally available. Remove non-default sampling parameters before switching, because they now return an error. Fast mode for Opus 4.8 was a research preview and was later deprecated, with removal on 2026-11-30.

## Use case and value
Example: change an agent's instructions halfway through a long session without losing the cached prompt.

## How to implement
Set the model to `claude-opus-4-8` and add `role: "system"` messages after a user turn, following the placement rules in the [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview).
