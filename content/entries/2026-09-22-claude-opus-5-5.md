## What's new
Claude Opus 5.5 (`claude-opus-5-5`) is a model for long-running agentic coding and knowledge work. It has a 1M token context window by default, 128k max output tokens and always-on adaptive thinking. It costs $4 / $20 per MTok, against $5 / $25 for Opus 5. The apps release notes say it performs at the level of Claude Fable 5.1 on most work and costs 40% less to run than Opus 5.

## When is it safe to use
Generally available. Thinking cannot be disabled on Opus 5.5: `thinking: {"type": "disabled"}` is not accepted, so remove it from existing code before switching.

## Use case and value
Example: a team running multi-hour coding agents on Opus 5 can move to Opus 5.5 for lower cost with the long context kept.

## How to implement
Set the model to `claude-opus-5-5`. See What's new in Claude Opus 5.5, linked from the [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview), for API changes.
