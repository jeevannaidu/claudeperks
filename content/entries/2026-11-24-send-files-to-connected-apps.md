## What's new
Claude can send a file to an app you have connected, or save a file that the app offers. File transfers with connectors are rolling out gradually.

## When is it safe to use
Beta. It is rolling out on Pro, Max and Ultra plans. On Team and Enterprise plans it is available when an owner turns it on.

## Use case and value
Example: Claude drafts a report and saves it straight into the document app you connected, instead of you downloading and uploading it.

## How to implement
On Team or Enterprise, an owner turns the feature on first. Then see Send files to connected apps and save files from them, linked from the [apps release notes](https://support.claude.com/en/articles/12138966-release-notes).
