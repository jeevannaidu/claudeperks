## What's new
Anthropic expanded its Cyber Verification Program (CVP) into three access tiers: Defense Access, Red Team Access and Specialized Access. Each tier reduces the cyber blocking classifiers for verified security professionals. The tiers cover Claude Opus 5.5, Claude Sonnet 5.5, Claude Mythos 5.1 and later models.

## When is it safe to use
Available by application only; the source gives no beta or preview label. Defense Access is for defensive work and individuals can apply. Red Team Access is for organizations doing authorized penetration testing. Specialized Access is limited to a few verified organizations. The announcement says data retention is required for enrolled organizations. Real-time blocks remain for actions that could cause physical harm or mass disruption.

## Use case and value
Example: a security operations team needs Claude to analyze malware and validate a vulnerability, which the generally available models may block. With Defense Access, those tasks get fewer interruptions. Generally available models still handle code review, patching known issues and alert triage without CVP.

## How to implement
Apply through the link in the announcement, choosing the tier that matches your work. The Help Center article explains who can apply, which plans qualify and how to turn on access after approval. Defense Access applications are expected to be answered within a few days; Red Team Access can take a few weeks.
