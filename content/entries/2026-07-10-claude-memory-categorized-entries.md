## What's new
Memory on Claude now works as a set of individual, categorized entries that Claude reads and updates during your conversations, replacing the previous daily memory summary. On 2026-08-25, memory began working across chat and Cowork in the cloud. Everything Claude remembers is listed under Topics in Settings > Memory, where you can edit or delete any item.

## When is it safe to use
Announced without a beta label. You can see, edit and delete every entry, and the release note says topics such as health or beliefs stay out of memory unless you turn them on.

## Use case and value
Example: Claude remembers your preferred report format between conversations, and you can delete that entry if it is wrong.

## How to implement
Open Settings > Memory to review Topics. See Use Claude's chat search and memory, linked from the [apps release notes](https://support.claude.com/en/articles/12138966-release-notes).
