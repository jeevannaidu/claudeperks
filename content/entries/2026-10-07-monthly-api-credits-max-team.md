## What's new
Max and Team plans now include monthly API credits for running your own apps and agents on the Claude Platform. They roll out over a few days.

## When is it safe to use
Generally available on Max and Team plans. You must link a Claude Console organization to claim the credits, which connects your plan and API billing.

## Use case and value
Example: a developer on a Max plan prototypes an app against the API using plan credits instead of a separate card.

## How to implement
Link a Claude Console organization in Settings > Billing (Max) or the organization settings (Team), as described in the [apps release notes](https://support.claude.com/en/articles/12138966-release-notes).
