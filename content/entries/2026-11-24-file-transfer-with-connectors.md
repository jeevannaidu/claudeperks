## What's new
Claude can send a file to an app you have connected. It can also save a file that the app offers. The rollout is gradual.

## When is it safe to use
Beta. It is available on Pro, Max and Ultra plans. On Team and Enterprise plans it works when an owner turns it on.

## Use case and value
Example: Claude drafts a report and sends it straight to your connected storage app, instead of you downloading and re-uploading it.

## How to implement
Connect an app, then ask Claude to send or save a file. On Team and Enterprise, an owner must enable it first. See Send files to connected apps and save files from them in the [apps release notes](https://support.claude.com/en/articles/12138966-release-notes).
