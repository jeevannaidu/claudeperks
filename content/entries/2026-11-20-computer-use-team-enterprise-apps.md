## What's new
Computer use lets Claude see your screen and work in the desktop apps you allow. It works in the new Claude experience in Claude Desktop, and from Claude on the web and Claude Mobile where Computer access is on. It is now in beta on Team and Enterprise plans.

## When is it safe to use
Beta, rolling out to organizations gradually. Claude works only in the desktop apps you allow.

## Use case and value
Example: an analyst asks Claude to copy figures from a desktop spreadsheet into a report, using the apps the analyst has allowed.

## How to implement
Follow Set up computer use for Team and Enterprise plans, linked from the [apps release notes](https://support.claude.com/en/articles/12138966-release-notes).
