## What's new
You can install an artifact that Claude makes for you as an app on your Mac or Windows computer. It gets its own window and icon and opens like any other app. It can interact with the operating system the way other apps do.

## When is it safe to use
Beta. Because an installed artifact can interact with your operating system, install only artifacts you made or trust. The notes do not list plan requirements.

## Use case and value
Example: a small budget calculator that Claude built in a chat becomes a desktop app you open from your dock, without keeping the chat open.

## How to implement
Follow the Install an app as an artifact article linked from the [apps release notes](https://support.claude.com/en/articles/12138966-release-notes).
