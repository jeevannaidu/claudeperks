## What's new
Text generated by Claude Opus 4.6, Claude Opus 4.5, Claude Sonnet 4.5 and Claude Haiku 4.5 carries Anthropic's text watermark on supported platforms. A list of supported platforms is in the help article on how Claude marks AI-generated content.

## When is it safe to use
Generally available, as far as the release note says. The note gives no status word, so this is inferred. The watermark might be missing if a request sets `temperature`, `top_p` or `top_k` to a non-default value.

## Use case and value
Example: a team that publishes model-written text can later check whether a passage came from Claude. Leaving sampling settings at their defaults keeps the watermark intact.

## How to implement
There is nothing to switch on. Leave `temperature`, `top_p` and `top_k` at their defaults. See the [Text watermark docs](https://platform.claude.com/docs/en/build-with-claude/text-watermark).
