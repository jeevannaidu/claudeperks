## What's new
Claude Desktop now has a release channel setting that decides which version you get when the app updates. Stable is the default and gets new versions less often, after more testing. Latest gets a new version about once a day, so fixes and features arrive sooner.

## When is it safe to use
Generally available on all plans in Claude for Mac and Claude for Windows. It is not available on Linux, Microsoft Store installs, or computers where your IT team has set a Claude policy. Latest can be less reliable than Stable. Switching back to Stable does not replace your version, so you stay on the Latest build until a newer Stable one ships.

## Use case and value
Example: a developer who wants new Claude Desktop features early picks Latest. A team lead who wants fewer surprises keeps Stable.

## How to implement
Open Settings > Desktop app, find Release channel, and select Latest or Stable. The change applies the next time Claude Desktop checks for updates. You need Claude Desktop 4.29.0 or later. See [Install Claude Desktop](https://support.claude.com/en/articles/10065433-install-claude-desktop).
