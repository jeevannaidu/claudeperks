## What's new
You can now choose which version of Claude Desktop you get when the app updates. Stable is the default and gets new versions less often, after more testing. Latest gets a new version about once a day.

## When is it safe to use
Not labelled beta or preview in the release notes. Stable stays the default, so nothing changes unless you switch. Latest may bring less-tested builds, so pick Stable for managed or work machines.

## Use case and value
Example: an individual who wants new features early picks Latest. A team that wants fewer surprises stays on Stable.

## How to implement
Open Claude Desktop and select a release channel, Stable or Latest. The exact menu location is in the help article [Choose a release channel](https://support.claude.com/en/articles/10065433-install-claude-desktop#h_ac219b3bde).
